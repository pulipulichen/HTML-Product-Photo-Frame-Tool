# CHANGELOG 0.0.1

## 0.0.1

### Added

- Initial release of a browser-based product photo frame composition tool.
- Layered image workflow with top-layer URL input and bottom-layer file upload.
- Drag-and-drop and click-to-select upload interactions for bottom images.
- Canvas drag interaction for adjusting bottom image position.
- Fit modes (`autoShort`, `width`, `height`) and bottom image scale slider.
- PNG export with timestamp-based filename generation.
- Local persistence for key settings and image state via `localStorage`.
- PWA assets (`manifest.json`, service worker, favicon) for installable app shell behavior.
- Playwright E2E test coverage for app shell rendering and core image workflow behavior.

### Documentation

- Added bilingual project documentation (`README.md` and `README_zh_tw.md`).
- Added changelog index and versioned changelog structure.
